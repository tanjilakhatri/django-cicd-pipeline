# 📌 Project Overview

This project demonstrates the implementation of a **Continuous Integration and Continuous Deployment (CI/CD) Pipeline** using **Jenkins** for a **Django Web Application**.

The pipeline automates the software development lifecycle by integrating source code from GitHub, building the application, executing automated tasks, and deploying the application with minimal manual intervention.

The project follows DevOps best practices to improve software quality, deployment speed, and development efficiency.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/CI-CD-Pipeline-Jenkins-Django.git
```

## Navigate to Project

```bash
cd CI-CD-Pipeline-Jenkins-Django
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Django Server

```bash
python manage.py runserver
```

---

# ⚙ CI/CD Pipeline Workflow

1. Developer writes code.
2. Code is pushed to GitHub.
3. Jenkins detects repository changes.
4. Jenkins pulls the latest code.
5. Build process starts.
6. Automated tasks are executed.
7. Application is deployed.
8. Deployment is verified.
